# Proyecto Python — Requisitos e Instalación

Este proyecto utiliza las siguientes librerías de Python:

- numpy
- matplotlib
- seaborn

---

# Requisitos previos

Antes de ejecutar el código, asegúrate de tener instalado:

- Python 3.8 o superior
- pip (administrador de paquetes de Python)

---

# Instalación de dependencias

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
pip install numpy matplotlib seaborn
```
Si usas Jupyter Notebook o Google Colab no es nesesario instalar las librerias puesto que ya las tren por defecto.
